# Commit Guide

Use short messages in the form `type: what changed`.

| Type | Use for |
|---|---|
| `feat` | a new feature |
| `fix` | a bug fix |
| `docs` | README / documentation |
| `refactor` | cleanup without changing behaviour |

## Suggested commit order

1. `feat: add model classes (Room, Guest, Booking, User, Admin)`
2. `feat: add custom exceptions`
3. `feat: add RoomService with room allocation`
4. `feat: add TariffService for bill calculation`
5. `feat: add BookingService for check-in and check-out`
6. `feat: add WaitingListQueue and ReservationService`
7. `feat: add occupancy report and input helper`
8. `feat: add Main menu for guest and admin`
9. `docs: add README and commit guide`
